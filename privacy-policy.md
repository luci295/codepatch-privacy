# Privacy Policy for CodePatch

**Last updated: September 24, 2026**

CodePatch respects your privacy. This Privacy Policy explains how the CodePatch browser extension collects, handles, uses, stores, and shares user data.

## Data Collection

CodePatch does not collect personal information or transmit personal information to the developer.

The extension does not collect browsing history, location information, authentication information, financial information, personally identifiable information, or user activity for tracking or advertising purposes.

CodePatch only processes information that the user intentionally enters or pastes into the extension, such as content placed in the CODE, FIND, and REPLACE fields, together with extension settings required for its functionality.

## Data Handling and Use

Information entered or pasted into CodePatch is used only to provide the extension's requested functionality.

CODE content is used as the working text on which FIND and REPLACE operations are performed.

FIND content is used to identify text selected by the user for replacement.

REPLACE content is used to replace the corresponding FIND content when the user activates the APPLY function.

Extension settings and working content may also be used to restore the extension's state between browser sessions.

CodePatch does not use user data for advertising, profiling, analytics, creditworthiness, or purposes unrelated to the extension's functionality.

## Data Storage

CodePatch stores working content and extension settings locally in the user's browser using browser-provided storage mechanisms.

This local storage allows CodePatch to preserve its state and user-entered content between browser sessions.

The developer does not operate a server or database that receives or stores this information.

## Clipboard Access

CodePatch accesses the clipboard only when the user explicitly activates a COPY or PASTE function within the extension.

Clipboard content is processed only as necessary to perform the requested copy or paste operation.

CodePatch does not monitor the clipboard in the background and does not transmit clipboard content to the developer or to external servers.

## Data Transmission

CodePatch does not transmit CODE, FIND, REPLACE content, clipboard content, or other locally stored user data to the developer's servers or to external servers.

The extension's core functionality operates locally in the user's browser.

## Data Sharing

CodePatch does not sell, rent, transfer, disclose, or share user data with the developer, advertisers, analytics providers, data brokers, or other third parties.

No user data processed by CodePatch is used for advertising or tracking.

## Third-Party Services

CodePatch does not use third-party analytics, advertising, tracking, or data-processing services for its core functionality.

User-entered working content is not sent to third-party services by CodePatch.

## Remote Code

CodePatch does not download or execute remote code as part of its functionality.

The extension's executable functionality is included within the installed extension package.

## Data Retention and Deletion

Information stored by CodePatch remains locally in the user's browser until it is cleared by the user, overwritten through normal use of the extension, or removed when the extension or its associated browser storage is deleted.

CodePatch provides controls such as DELETE and CLEAR that allow users to remove working content stored by the extension where applicable.

Because CodePatch does not maintain a remote database containing user data, the developer does not retain a separate remote copy of this information.

## Security

CodePatch is designed to minimize privacy risks by processing its working data locally and by not transmitting user-entered content to developer-controlled servers.

## Changes to This Privacy Policy

This Privacy Policy may be updated if CodePatch functionality or its data-handling practices change.

Any updated version of this Privacy Policy will be published on this page with a revised "Last updated" date.

## Contact

For questions regarding this Privacy Policy or CodePatch's data-handling practices, users may contact the developer using the contact information provided on the CodePatch Chrome Web Store listing.

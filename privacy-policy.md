# CodePatch Privacy Policy

**Last updated: September 22, 2026**

CodePatch is a browser extension designed to help users safely apply FIND/REPLACE code modifications.

## Data Collection

CodePatch does not collect, sell, transmit, or share personal information or user code with the developer or third parties.

CodePatch does not use analytics, tracking services, advertising services, or external servers to collect user data.

## Local Storage

CodePatch may store CODE, FIND, REPLACE, and undo information locally in the user's browser using the browser's extension storage functionality.

This local storage is used only to preserve the user's work when the CodePatch side panel is closed or reopened.

The stored content is not transmitted to the developer or to external servers by CodePatch.

## Clipboard Access

CodePatch uses clipboard permissions only when the user explicitly activates a clipboard function.

Examples include:

- Pasting code into the CODE section
- Pasting text into the FIND section
- Pasting text into the REPLACE section
- Copying modified code from the CODE section
- Copying the CodePatch AI instructions

CodePatch does not automatically monitor or collect clipboard contents.

## AI Services

CodePatch does not connect directly to ChatGPT, Gemini, or any other AI service.

The AI Instructions button only copies instructions to the user's clipboard.

If a user chooses to paste CodePatch instructions, source code, or other content into an external AI service, that action is performed directly by the user and is subject to the privacy policy of that external service.

## Remote Code

CodePatch does not download or execute remote JavaScript or WebAssembly code.

All executable extension code is included within the CodePatch extension package.

## Website Content and Browsing Activity

CodePatch does not monitor browsing activity, browsing history, or the content of websites visited by the user.

## Data Sharing

CodePatch does not sell or transfer user data to third parties.

CodePatch does not use user data for advertising, creditworthiness, lending purposes, or purposes unrelated to the extension's functionality.

## Changes to This Privacy Policy

This Privacy Policy may be updated if CodePatch functionality changes. Any updates will be published on this page.
